# Instant-Ready-Up
A quality of life Rocket League plugin that instantly makes the player ready up upon completion of a game in casual and private matches (it also works in competitive).

The plugin will be set to ON every time the game starts up, and to turn the plugin off, go to the tab for this plugin in the bakkesmod plugin tab, and click the on-off button that is there (the button showing ON means the plugin is on, and the button showing OFF means the plugin is off).
